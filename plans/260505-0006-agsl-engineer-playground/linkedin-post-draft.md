# LinkedIn Post Draft — AGSL Engineer Playground

**Hook line**

I built an open-source Jetpack Compose playground that teaches AGSL (Android Graphics Shading Language) one runnable lesson at a time — 24 lessons + 3 wow showcases — and shipped it under Apache-2.0.

**Why it matters for Android engineers**

AGSL ships with Android 13+ and turns Compose into a fragment-shader playground (ShaderBrush + RenderEffect). Tutorials are scattered. This repo packages them into a swipeable, on-device curriculum so you stop reading and start *running* shaders.

**What's inside**

- 4 categories: Basics → SDF → Noise → Post-FX
- 3 LinkedIn-worthy showcases: Liquid Glass, Aurora Ribbons, Raymarched Sphere
- ~150 LOC per lesson, runtime compile-error guard, sliders for every uniform
- Single-module, no DI, minSdk 33, license Apache-2.0
